# 对话设置：分段、朗读与语音输入

入口：桌宠小屋 → 智能陪伴 → 对话设置。语音服务与聊天模型独立配置，可分别选择本地或云端。默认关闭；旧版启用过的 Windows 朗读设置首次启动时自动迁移。主程序仍为 1.5.0。

## 对话分段

跨过本地日期，或默认 **30 分钟**没有发来新聊天消息，就视为上一段对话结束。可在本页调整“对话空闲结束时间”（5–1440 分钟）并保存；跨天结束始终生效。只计算你发出的聊天消息，摸头、大肥鱼的回复、自动提醒都不会延长时间。

下次开口从新对话开始，旧练习的问题、等你评分的卡片或未完成操作不会自动续接。短时间内继续聊天仍保留本段上下文；明确想继续之前的练习时，请说明要继续的内容，大肥鱼需重新确认软件的当前状态。

共同记忆、学习计划、提醒设置都保留，旧聊天仍可查看（沿用最多 400 条的历史容量）。结束不是清空记忆，也不会停止已保存的学习提醒。进行中的旧模型请求或工具链会取消；工具已完成的外部操作无法撤回。关闭状态会保存，重启或后来调长间隔不会让已经结束的对话自动恢复。

## 语音朗读（TTS）

### 中日分声：微软中文 + 雨晴はう

在“声音分配”选择 **中日分声：微软中文 + 雨晴はう**，再保存：

- 中文使用 Windows 已安装的微软中文声音，可选择音色，留空自动选择。本地朗读无需密钥。
- 日文使用 **VOICEVOX:雨晴はう（ノーマル）**。地址通常为 `http://127.0.0.1:50021`，填写服务根地址，不加 `/synthesis`。程序通过 `/speakers` 确认角色及普通说话风格的实际 ID，再调用 `/audio_query` 与 `/synthesis`。
- 可选择 VOICEVOX 解压目录、软件目录或 `vv-engine` 目录，勾选“按需启动”。首次检查/朗读时启动该目录中的 Windows 引擎；不下载模型，不打开编辑器。现有手动启动的服务直接复用；退出大肥鱼、重新保存语音配置时，仅关闭大肥鱼自己启动的引擎。
- “日语合成设备”可选 CPU 或 GPU / 核显。Windows 的 DirectML 版 VOICEVOX 可使用兼容的 AMD / Intel 核显；需安装对应显卡驱动。GPU 模式启动失败会明确提示，可切回 CPU；不会静默冒充核显加速。依据：[VOICEVOX GPU 说明](https://github.com/VOICEVOX/voicevox_core/blob/main/docs/guide/user/gpu.md)。
- “CPU 合成线程数”设为 0 时自动使用逻辑处理器数量的一半（最少 1、最多 16），也可指定 1–64。设备、线程数仅用于大肥鱼自动启动的引擎，保存后下次启动生效；已经手动运行的 VOICEVOX 需在该软件里调整。线程更多不一定更快，核显模式首次加载模型也可能比 CPU 慢。
- “检查日语声音”验证连接与目标角色；“试听语言”可分别测试自己的中文或日文句子；“试听中日切换”播放固定的中文→日文→中文示例。
- 单一声音模式下的本地/云端配置和密钥保留，中日分声时不调用这些兼容 TTS 服务。

聊天模型在**同一次正文生成**中使用 `<voice lang="zh">…</voice>` / `<voice lang="ja">…</voice>` 标注片段，中文解释里引用的日语单词也分开处理。主进程提取语言，聊天气泡和历史展示净正文，语音按片段顺序播放。发给模型的后续上下文保留已有语言元数据，避免它模仿没有标签的历史格式。纯汉字如“先生”按模型标注路由，不使用假名/汉字检测来猜测语言，也不逐段追加分类请求。若模型漏标、嵌套或未闭合标签，只补发一次不带工具的格式修复请求，并验证正文没有变动；仍失败则保留文字、提示并跳过朗读。模型语义上分错语言仍可能读错，可在当前对话要求它纠正。工具参数、记忆评价和日记生成不注入此协议。旧回复和手动未指定语言的试听默认中文。开始录音、停止按钮、休眠和退出继续取消排队片段与合成请求；VOICEVOX 已开始的服务端计算可能运行至完成。

语音订阅早于角色素材加载完成，首次聊天不会因角色还在加载而丢失；微软声音列表初次为空时等待 `voiceschanged`（最多 5 秒），等待期间也可停止。

此模式先覆盖中文、日文，未承诺其他语言的自动音色切换。Markdown 图片、网址、代码块继续不朗读。声音由 AI 合成；输出或分享日语音频时保留 `VOICEVOX:雨晴はう` 署名，参阅[角色页面](https://voicevox.hiroshiba.jp/product/amehare_hau/)及其使用说明。应用不附带 VOICEVOX 程序和角色模型。

### 单一声音

- **本地 → Windows 系统声音**：使用已安装的本地声音，无需密钥或服务。日语练习可在 Windows“时间和语言 → 语音”安装日语声音，在这里选择。
- **本地 → 本机 TTS 服务**：需要先运行兼容音频接口的本地引擎。填写完整接口地址，例如 `http://127.0.0.1:8880/v1/audio/speech`，以及该引擎实际支持的模型和声音 ID。
- **云端**：填写 HTTPS 完整接口地址、模型、声音 ID 和服务自己的 API Key。默认示例使用 OpenAI 音频接口；其他服务须支持相同请求格式。DeepSeek 聊天模型的地址和密钥不会自动用于语音。

对话设置上方的 **TTS 试听** 提供句子输入框，默认“这是我的声音”，可以改成自己的句子（最多 1000 字符）。保存声音配置后点“试听声音”，使用已保存的来源、声音、语速和音量播放；输入文字不需要保存，也不会发送聊天。“停止试听”可取消合成请求与播放。即使未勾选自动朗读，也可主动试听；空白句子不能提交。

勾选自动朗读后，收到完整回复及有效语言标注，再按句开始合成和播放；Markdown 图片、URL、代码块不会照读。前句播放时，后台提前合成下一句；最多缓存当前句和下一句，不等待整篇音频。合成请求保持一个在途，避免 VOICEVOX 内部排队争抢和本机兼容服务的并发拒绝；CPU 推理本身仍使用多线程，日文可使用核显加速。这不是聊天模型边输出边朗读，也不是单段 WAV 流式传输。

“停止思考与朗读”同时取消排队朗读、系统声音、音频播放和正在进行的合成请求；迟到音频不会恢复播放。每轮播放独立标识，旧轮次的取消不会打断新回复。开始录音、切页、休眠和保存配置继续遵循原有取消机制。

## 语音识别（ASR）

- **本地 → 兼容 /audio/transcriptions**：先运行本地识别引擎，填写完整路径和它实际加载的模型名称，例如 `http://127.0.0.1:8080/v1/audio/transcriptions`。
- **本地 → whisper.cpp /inference**：使用 whisper-server，例如 `http://127.0.0.1:8080/inference`。可选择含 `whisper-server.exe` 的引擎目录、GGML `.bin` 模型，勾选按需启动并保存。录音前自动启动服务，模型加载完成后才打开麦克风；默认 CPU 8 线程，可调整。模型通过固定启动参数加载，不接收聊天模型传入的命令或路径。已有手动服务直接复用；保存配置和退出只关闭桌宠自己启动的进程。
- **云端**：填写支持兼容转写接口的 HTTPS 地址、语音识别模型与独立 API Key。结束录音后才上传本段音频。

可选择自动判断、中文、日语、英语或韩语。程序不附带或自动下载识别模型；whisper.cpp 的按需启动需要用户先选择引擎与模型。首次安装模型后可点 **检查识别服务**，Whisper 检查模型加载后的健康状态；兼容接口检查只确认 HTTP 接口可访问，实际识别仍需录音测试。兼容接口的模型名称为空时，在录音前直接说明缺少配置。

启用并保存后，小屋聊天和桌面快捷聊天均有麦克风按钮。点击开始，再次点击结束并识别；每段最长 60 秒。开始录音会停止朗读，避免声音回录。识别成功后立即将这句话作为聊天消息发送给大肥鱼，无需确认或再点发送，回复继续使用已配置的朗读和表情。输入框原有的键盘草稿保留，不会附带发送。聊天模型未就绪或正在回复时暂不能开始新录音；识别为空、超过单条 4000 字或取消识别均不发送。发送失败时显示错误和识别文字，保留原草稿。软件操作仍通过原有聊天通道和已授权工具执行。

小屋对话设置提供独立录音测试，只显示识别文字，不发送聊天；无需配置聊天模型也可测试。录音/识别过程中切页、收起快捷聊天、关闭窗口、保存配置、休眠或退出，会取消该流程并清理麦克风。未结束的录音不上传；达到 60 秒上限会自动结束并识别，聊天入口随后自动发送。取消已经发出的云端识别会中断本地请求，但不能撤回服务已经收到的音频。音频只在内存中处理，不写录音文件。

如果没有设备或权限被拒绝，界面会显示原因；请自行检查 Windows 麦克风隐私设置。接口错误会显示 HTTP 状态和检查提示，系统不会自动改用其他语音服务。桌面快捷聊天也直接显示准备、录音、识别和错误状态，长提示可悬停查看全文。点一次麦克风开始，说完后再点一次结束，随后自动识别并发送。

## 接口和保存方式

- TTS：`POST` JSON，字段 `model`、`input`、`voice`、`speed`、`response_format: "wav"`；接收 RIFF/WAV。按句界拆分，每段最多 180 个 Unicode 字符，英文小数点不当作句界，句末引号保留。
- ASR：`POST multipart/form-data`，上传 `file=recording.wav`、`model`、`response_format=json` 和可选 `language`；读取 JSON 的 `text`。whisper.cpp 不发送 `model`，自动语言传 `auto`。
- 录音格式固定为 16 kHz 单声道 16 位 PCM WAV。单段不超过 60 秒，HTTP 请求 120 秒超时；TTS 响应不超过 20 MiB，转写响应不超过 128 KiB。
- 本地只允许 `127.0.0.1`、`localhost`、`[::1]`；云端要求 HTTPS。地址不能内嵌密钥或查询参数；不跟随重定向。摄像头权限始终拒绝，麦克风只在受信任聊天窗口发起录音后临时开放。
- 配置与四份独立加密凭证保存在用户数据目录的 `conversation-settings.json`。主进程使用 Electron safeStorage 加密；renderer 只收到“是否已保存”，不返回密钥。清除密钥需点击对应按钮再保存。本地/云端切换各自保留配置。

接口依据：[OpenAI TTS](https://developers.openai.com/api/docs/guides/text-to-speech)、[OpenAI 文件转写](https://developers.openai.com/api/docs/guides/speech-to-text)、[whisper.cpp server](https://github.com/ggml-org/whisper.cpp/tree/master/examples/server)。模型和声音是否可用，以你选择的服务为准。

当前为点击录音、完成后转写，不包含唤醒词、持续监听、流式双向通话、声纹克隆或自动下载模型。真实账户和本地模型的识别质量，需要配置服务后通过试听/录音测试确认。
