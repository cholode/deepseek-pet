# 长期成长与学习工作室

主程序版本仍为 1.5.0。本次把“相处反馈 → 表达习惯”和“资料 → 备课 → 授课 → 复盘”接成可持久化的闭环。成长不会训练或替换底层大模型权重，也不会让模型自行修改应用代码。

## 使用

小屋 → 智能陪伴 → **性格成长**：查看温柔表达、俏皮程度、主动提议、解释详细度，逐项锁定、整体关闭或恢复到某次变化前。一次反馈不会立即改写性格。至少三条不同用户消息中的一致明确反馈才改变一点；每项每天最多两点，自动变化保持在 10–90。依据必须是用户原话的连续摘录。短期情绪仍由原心情系统处理，核心身份和工具权限不会随性格变化。

小屋 → 智能陪伴 → **学习工作室**：

1. 建立课程，填写名称、目标、教材版本（未知可留空）、程度与每课计划分钟数。
2. 导入自己有权使用的 PDF、EPUB、TXT、Markdown、HTML，粘贴资料或读取公开 HTTPS 网页。每份资料最多 16 MiB，保存提取原文、来源、哈希和页/段号。PDF 保留物理页码，EPUB 使用章节序号，文本按段编号。扫描件需先 OCR，不把“未提取到文字”当作读完教材。
3. 点“准备下一课”，或直接和大肥鱼说“帮我准备新标日初级课程”。未提供材料时会尝试搜索。搜索结果先筛相关性，正文再检查是否足以教学；搜索摘要、书目介绍、错误网页不能充当教材正文。未取得教材正文、关闭检索或资料有限时先准备通用入门课，并在课件里标明范围；之后可以补充教材。不会声称获取了并未读到的整本教材。
4. 查看步骤结果，暂停、继续、取消或重试。可指定开始时间，并保存工作流模板复用。
5. 备课完成后，课件出现在课程页，可以预习讲解、核对引用、打开 Markdown 文件。点“老师带我学”，或在聊天里请求上课，进入默认的“主动回忆与交错”课堂。可直接回答、追问、要求讲短一些或提示，老师围绕当前任务继续；原“开始 / 继续这课”保留自主逐题练习。课堂回答既可在小屋输入，也可在聊天中输入或使用已配置的语音识别。
6. 每题记录真实答案、是否使用提示、评分、反馈和作答用时。完成后产生复盘，记录错题与教学策略。可反馈“讲慢一些”“多用场景练习”；下一次备课会参考这些反馈。
7. 在课程计划中选择已授权的学习记录插件、启用自动准备下一课、设置学习日和提醒时间。这些开关初始关闭。

聊天跨天或超过对话设置中的空闲时间时，课堂也暂停；课程不会丢失，但不会自动接着昨天提问。重新打开应用同样暂停课堂，等用户明确继续。后台备课检查点会恢复。提醒和后台执行需要应用运行；同一天补一次错过的提醒，不补发过去日期。

## 默认教学方法

2026-10-29 对十种方法做了两轮真实模型并发比较：第 1–3 课范围、两种模拟学生，共 120 场景、960 次教师回复。教学逻辑、像人程度、教学质量等权，主动回忆与交错以 81.63 分最高；独立匿名 AI 审查同样排它第一。完整设计、逐项评分、对话与局限见 [教学评测报告](evaluations/teaching-2026-10-29/REPORT.md)。这是自编同范围资料上的模拟测试，不能证明真人长期记忆效果或整本教材覆盖。

带学采用“短诊断 → 最小讲解 → 闭卷回忆 → 换词交错 → 稍后再取回 → 复习约定”。它根据学生实际回复回退、缩短或换情境，不把阶段当强制闯关。每次最多一个主要问题；当前问题和公开对话持久保存，参考答案不出现在对外授课工具结果中。新课堂快照默认方法，旧课堂重启后保留原方法。

“提示”“讲短一点”“今天先停”等请求不当作答题成绩；提示状态会延续到后续真实作答，区分提示后完成和独立回答。同一请求只记录一次。点击“暂停课堂”可以以后继续；至少有一次真实作答后可点“结束本课并复盘”。同一教案重复练习不会重复推进课程目录。评分仍可能出错，可以向老师指出；一次答对不表示长期掌握。

## 状态与职责

| 文件 | 作用 |
| --- | --- |
| `src/shared/growth.ts`、`src/companion/growth.ts` | 成长数据校验、证据积累、限幅、锁定、回退和表达提示 |
| `src/shared/studio.ts` | 课程、资料、课件、步骤图、课堂、IPC 的严格契约 |
| `src/companion/study.ts` | 步骤依赖校验、按词语检索资料片段、原文引用核对、学习表现汇总和课件输出 |
| `src/companion/teaching.ts`、`src/shared/teaching.ts` | 十种教学策略、带学输出契约与单轮执行器，评测与产品共用 |
| `src/shared/teaching-selection.json` | 默认方法、评测范围与选择依据；新课堂会快照方法 ID |
| `src/main/studio/sources.ts` | 受限网页下载、检索、PDF/EPUB/文本提取 |
| `src/main/studio/model-output.ts` | 容错解析模型文本、规范字段、生成题目编号，不伪造答案或评分 |
| `src/main/studio/store.ts` | 原子写入与串行落盘、重启恢复 |
| `src/main/studio/service.ts` | 模型规划、持久执行器、课堂真实作答绑定、复盘、插件记录和提醒 |
| `src/renderer/panel/StudioPanel.tsx`、`GuidedClassroom.tsx`、`GrowthPanel.tsx` | 小屋管理、可滚动带学对话、练习和成长界面 |

学习数据放在用户数据目录的 `learning-studio/studio.json`，Markdown 课件在同目录 `courseware/`。聊天过期/清空不会删除课程。成长保存在原 `companion.json`。读取损坏的学习文件会停用学习工作区并保留原文件；不能用空默认数据悄悄覆盖。

备课工作流可组合的步骤为 search → read → outline → lesson → check → publish；已有资料可不搜索。课后流程是 reflect，以及用户已配置时的 review-export。模型提交声明式 DAG，执行器验证循环、重复 ID 和必需依赖，再逐步落盘执行。步骤不是任意代码、Shell 或下载的脚本；新增能力仍需宿主实现或软件插件提供。

按用户要求默认放宽备课校验：模型输出允许代码围栏、说明文字、额外字段和数字字符串；引用、提示、补充讲解和词表可省略，题目 ID 由宿主统一生成。无法解析时自动请求一次格式修复；仍缺少可用讲解、题目或参考答案才暂停。评分缺失不会补成“答对”。落盘和 IPC 继续使用统一数据结构。

模型计划不完整或依赖有误时回退标准备课流程，不运行未知步骤。引用核对忽略排版标点、空格和全半角差异；无法定位的引用显示“原文待核对”，不阻断发布。资料不足、检索失败、模型检查提出修改意见或检查请求失败时，保留提示并继续保存可用课件。`checked` 表示已整理核对意见，不表示质量保证。课件、聊天授课工具和小屋都能读到这些说明；可以直接上课，不需要额外确认。

后台任务默认最多调用模型 20 次，超出后保存当前进度、显示原因，用户可检查后重试或调整预算。这不是桌面聊天的工具轮数限制。单个模型调用仍使用原设置的超时，备课输出上限单独提高到 7000 tokens。

课堂评分用真实提交文本，聊天 `study_tutor` 与 `study_answer` 不接受模型传入的“学生答案”。带学工具使用绑定的实际消息，输出只含公开回复与当前问题；外围聊天应直接转达，避免重新讲一遍。单轮教师温度为 0.4，与评测一致，不改用户保存的普通聊天配置。同一个消息/请求 ID 只记录一次。用时不含评分模型等待，暂停、隔夜和重启不会计成整夜学习。这里的独立答对/近期得分只是课堂表现，不是科学测得的长期掌握概率；提醒、再次回忆与间隔复习仍然必要。

## 数据与外部能力边界

资料和作答会发送给用户配置的模型；普通模式仍不需要联网。只允许 HTTPS 公网资料，无账号、密码或特殊端口。每次跳转重新检查 DNS，连接固定到检查过的地址，不允许借教材网址访问本机或局域网。网页脚本不执行，资料和用户答案不是工具指令。

插件清单可声明 `learningRecordTool`。只有已启用、签名匹配且逐项授权的工具能成为课程记录目标。该接口由学习宿主调用，不暴露给模型构造学生答案。接口以课堂 `sessionId` 幂等写入，包含真实作答/反馈、约计分钟、总结、纠错和本课词表。响应丢失保留“结果待核查”，不会因为超时就自动重复外部写入。具体插件说明保留在对应插件文件夹。

外部写入与备课是不同的副作用：普通备课步骤中断可重做，重启时正在进行的插件写入标记为待核查。不会回滚已经写进外部软件的内容，也不会把“请求已发出”显示成“记录成功”。
