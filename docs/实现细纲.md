# 中文实现细纲

## 每晚自动日记（1.4.5）

- 每天本机21点自动写，无需打开小屋。关机漏写的日期在下次启动依次补上，按原日期命名；从首次启用本版当天开始记录。
- 自动进度独立持久化；正文带隐藏去重标记，已生成但未完成提交的正文可重启续写，避免重复调用模型或追加同一天。
- 失败或手动停止15分钟后重试；休眠暂停、恢复检查。自动写作等待聊天完成，不受人物窗口显隐影响。
- 日记页展示21点、待补天数、最近完成日和重试时间；保存位置设置及手动追加入口保留。

## 日记（1.4.4）

- 小屋的智能陪伴新增“日记”页，提供手动写作、按日期查看、设置/选择/打开目录和恢复默认位置。
- 默认识别源码根目录；便携和安装独立运行各有稳定回退位置，避免写入解压缓存。配置与陪伴数据分离，写权限验证成功后保存地址。
- 已配置模型时整理当天对话为第一人称日记；普通模式写明确标注的本地纪事。模型失败可重试或停止，不修改旧日记，也不调用 MCP。
- 同日追加，按点击时的本地日期命名；读写仅限受校验日期的日记文件，写入使用临时文件提交。个人日记排除 Git 与发布包。

## 脚下快捷菜单（1.4.3）

- 聊天输入下方显示“聊天 / 状态”，两页保留挂载以保存草稿和正在发送的请求；菜单支持鼠标和方向键切换。
- `pet-chat-status.ts` 从既有动作、设置和衰减心情生成摘要；状态刷新不请求模型，不向悬停窗口传完整配置或记忆。
- 主进程按所选页调整窗口高度，沿用脚底锚点、底部临时上移及用户移动后不恢复旧坐标的规则。

## 配置存储（src/main/settings.ts）

- 读取配置：创建用户目录 → 读取 JSON → 校验配置；错误文件改名备份后使用默认值。
- 保存配置：先校验 → 更新内存真源 → 加入串行写队列 → 写临时文件 → 原子改名。
- 等待保存：等待既有写队列完成，退出时保存位置。

## 动作包存储（src/main/packs.ts）

- 解析安全路径：拒绝绝对路径、父目录、反斜杠、冒号和编码路径；解析后必须仍在包根目录。
- 检查目录：拒绝符号链接和目录联接，检查文件数、总大小、文件类型及图片头尺寸。
- 读取动作包：读取清单 → 解析 motion 与 group → 检查帧图片及画布 → 分配受限资源令牌。
- 生成候选快照：加载内置包 → 加载用户包 → 对坏包保留旧版 → 校验完整引用图。
- 提交快照：替换 registry，释放不再被当前快照使用的资源授权。

## 窗口与交互（src/main/index.ts、src/shared/geometry.ts）

- 创建桌宠窗：透明无边框、禁止脚本能力，加载本地页面，恢复合法位置。
- 创建小屋窗：独立中文控制面板，不建立第二个随机驱动。
- 采样鼠标：获取 DIP 坐标 → 命中区判断 → 根据状态切换整窗穿透 → 同步状态。
- 开始拖动：校验锁定 → 取消自主移动 → 立即采样位置 → 设置拖动状态。
- 结束拖动：立即采样终点 → 清理按下状态与安全计时器 → 保存位置 → 通知运行时。
- 自主移动：夹取工作区内终点 → 主进程按时间插值 → 到期或取消停止。
- 恢复交互：关闭全部穿透，显示桌宠，重新开启采样；托盘和快捷键都能调用。

## 数据校验（src/shared/schema.ts）

- 检查动作：关键帧起止、递增时间、属性白名单、通道归属；逐帧时长唯一、画布一致。
- 分析动作树：顺序求和，并行取最大；并行分支通道有重叠就拒绝。
- 建立目录：组合完整 ID → 检查重复和未知引用 → 计算预计时长及能力目录。
- 应用用户覆盖：按全局组 ID 叠加启用、资格、权重和冷却，不改内置文件。

## 执行与控制（src/renderer/pet/engine.ts、PetRuntime.ts）

- 编译时间表：把顺序/并行树转换为统一逻辑时间上的叶子任务。
- 推进动作组：先结束旧叶子，再启动到期叶子，按毫秒插值更新。
- 结束动作组：递归释放句柄，恢复姿态，发送唯一终态，忽略迟到回调。
- 提交命令：校验结构 → 幂等缓存 → 模式/到期/锁定/优先级/可用性 → 取消旧实例 → 创建新实例。
- 更新目录：新目录先校验成功，然后取消旧动作，切换 revision 并恢复随机调度。

## 普通驱动（src/renderer/pet/behavior.ts）

- 筛选候选：资格、权重、冷却、用户空闲、指针和漫游 → 排除历史 → 有序放宽历史。
- 加权选择：使用注入随机数，权重零永远不入池。
- 安排下一次选择：唯一计时器和 epoch；动作开始取消计时器，终态之后重排。
- 暂停/恢复/停止：清理旧定时器；恢复不复制计时器；空池低频重试。

## 角色与界面（Avatar.ts、mount.ts、panel/Panel.tsx）

- 加载图层：预加载受限纹理，创建节点层级和基准支点。
- 开始叶子动作：关键帧、帧动画、表情、特效、气泡、主进程移动都返回可清理句柄。
- 处理手势：立即按压反馈、延迟单击、双击取消单击、超过阈值启动拖动、取消和失焦清理。
- 小屋页面：订阅运行时快照；展示动作状态、动态动作列表、表单和错误；通过白名单桥接发送命令。

文件名和 TypeScript 公共接口保留工程惯用英文，本细纲用中文解释其职责和调用关系；可运行源码没有被文档替代。
