# Anki 日语学习插件发布记录

插件版本由本目录的 `software-plugin.json` 独立维护，不跟随大肥鱼主程序版本。`schemaVersion` 是清单格式版本，不是插件发布版本。

## 1.2.0

- 接入学习工作室课程记录，按稳定课堂编号重试去重；真实作答、纠错、词表和用时分别保留。
- 复习取卡改用 Anki 原生 GUI 队列与计时；显示真实评分选项和预计间隔，用户自评后使用 `guiAnswerCard`。
- 读取当天实际复习次数、不同卡片数与 Anki 耗时；卡片转文本保留段落边界。
- 更新插件后重新连接并授权。主程序版本保持 1.5.0。详见 [设计与验证](docs/LEARNING_STUDIO.md)。

## 1.1.0

- 新增独立授权的 `anki_launch`：可在聊天中请求打开 Windows Anki，无需预先保存学习计划。
- 限定绑定目录中的 Anki 程序，支持标准安装及 app/data 布局；保留已有数据目录，不执行任意命令。
- 检查 AnkiConnect 就绪，区分发起启动、已连接及当前用户不匹配；支持取消等待，抑制并发和短时间重复启动。
- 大肥鱼主程序保持 1.5.0，原学习及复习功能不变。

## 1.0.0

- 通过本机 AnkiConnect 读取状态、保存学习计划、记录实际对话与生词，以及分阶段取题、揭示和用户自评。
- 提供可在小屋开启的学习计划提醒；日志卡暂停，同轮记录重试去重。
- 支持独立 ZIP 分发，MCP 握手与打包名称均读取插件清单版本。
- 适配当前大肥鱼 1.5.0 的声明式设置、提醒和内置 Node 运行时。此前开发过程中误将插件接入标记为主程序 1.6.0，现已更正，插件版本保持 1.0.0。
- 已知取卡队列、复习计时及进度统计问题尚未修复，见 [20词流程评估](docs/USER_AUDIT.md)。
