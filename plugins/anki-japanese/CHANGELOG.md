# Anki 日语学习插件发布记录

插件版本由本目录的 `software-plugin.json` 独立维护，不跟随大肥鱼主程序版本。`schemaVersion` 是清单格式版本，不是插件发布版本。

## 1.0.0

- 通过本机 AnkiConnect 读取状态、保存学习计划、记录实际对话与生词，以及分阶段取题、揭示和用户自评。
- 提供可在小屋开启的学习计划提醒；日志卡暂停，同轮记录重试去重。
- 支持独立 ZIP 分发，MCP 握手与打包名称均读取插件清单版本。
- 适配当前大肥鱼 1.5.0 的声明式设置、提醒和内置 Node 运行时。此前开发过程中误将插件接入标记为主程序 1.6.0，现已更正，插件版本保持 1.0.0。
- 已知取卡队列、复习计时及进度统计问题尚未修复，见 [20词流程评估](docs/USER_AUDIT.md)。
