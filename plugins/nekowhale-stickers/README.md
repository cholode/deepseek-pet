# 大肥鱼表情包插件

插件版本 **1.0.0**，独立于大肥鱼主程序版本。把 [dsh-nekowhale-stickers](https://github.com/Loping151/dsh-nekowhale-stickers) 的表情知识库适配为桌宠的“表情包”功能，收录 322 张现成 GIF：大肥鱼 286 张、大肥鱼和 GPT 娘 36 张。

## 使用

1. 打开桌宠小屋 → **表情包**。无需安装 DSH、Node.js 或另一个桌宠。
2. 搜索“开心”“摸鱼”“期待”等名字或场景，点一张下载并预览。**在气泡预览**只展示图片，不记录为真实聊天或学习内容。
3. 开启 **允许大肥鱼使用表情包**，然后正常聊天，例如“发一个期待的表情”“今天背完单词啦，庆祝一下”。智能陪伴仍使用你已经配置的模型，模型须支持工具调用。
4. 模型可以先搜索再选择；只有成功准备好的 GIF 才会附到最终回复，每次最多一张。图片保存在聊天记录中，气泡和小屋都能播放。

可选择发送频率、可用套组，或在预览处勾选“不让大肥鱼自动选用这张”。少量、自然、活泼是模型选用风格提示；**每次回复都发送**则会为每次桌面聊天回复附一张，优先用模型已选的图片，漏选时由宿主按回复内容补选。补选无需额外调用模型，优先复用缓存并尽量避免近期重复。长回复仍保留完整图片，图片不会被朗读。

没有允许使用的图片、离线缓存为空或下载失败时，保留文字并在表情包页提示原因，不使用被禁用的图片、不冒充发送成功。自动补选最多等待 5 秒；取消聊天会一起取消。这个功能不额外创建主动消息或提醒，外部 QQ 渠道不自动附图。需要包含此功能的新版宿主；数据插件版本仍为 1.0.0。

## 下载与离线

- 默认关闭模型自动选用，浏览目录不联网。首次预览或选用一张表情时，主进程从 `https://kiriyuki.com` 下载该 GIF。
- 下载有 20 秒超时、8 MiB 单文件上限，验证文件大小、GIF 头、画布尺寸及上游 SHA-1 前缀。失败可重试，不会当作发送成功。
- 缓存位于用户数据目录 `stickers/cache`，总预算 128 MiB，超限淘汰较旧缓存；清理缓存保留设置。未缓存的旧聊天图片会显示提示，可以回小屋重新预览下载。
- 开启 **仅使用已下载表情** 后不联网下载；已缓存图片可在重启、断网后继续显示。取消聊天或更改授权会阻止迟到下载被附到回复。
- 普通 Markdown 外链图片和本机文件仍不加载；只有经过宿主校验的表情缓存可显示。

## 独立更新

本插件为数据插件，不执行目录中的 JS、Python 或可执行程序，与“可操作软件”插件及动作包分开。

解压独立 ZIP 后，在小屋“表情包”页点击 **导入／更新插件**，选择包含 `sticker-plugin.json`、`catalog.json`、`NOTICE`、`LICENSE`、`LICENSE-ASSETS` 的目录。宿主校验完成后才替换当前目录；更新后自动选用关闭，可查看来源再启用。无需重新打包主程序。

发布命令：`npm run pack:stickers`。版本由本目录的 `sticker-plugin.json` 管理。

本版接入现成 GIF 的搜索、选用、缓存和显示，没有包含上游的自定义文字制图、头像合成、网页桌宠或账户余额功能；当前展示渠道是桌面气泡与小屋聊天，不向 QQ 发送图像。

### 问候时的表情响应

新对话或连续问候中只含“上午好”“你好”等招呼时，聊天无需通过模型多轮搜索/发送表情，宿主在“每次回复”模式继续自动附图，优先当前允许使用的已有缓存，避免为更换新图等待网络。真实软件或学习请求仍走正常工具流程；禁用、套组、离线和单张限制保持。此项是宿主调度改进，表情数据插件版本不变。
