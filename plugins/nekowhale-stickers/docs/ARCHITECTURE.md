# 表情插件架构

`sticker-plugin.json` 描述独立版本、素材站来源及署名。`catalog.json` 是标准化目录，包含每张表情的情绪、场景、动作描述、双人方向、预期大小/尺寸和哈希。宿主仅加载数据，不执行这个目录中的程序。

`src/main/stickers/plugin.ts` 校验清单与目录，原生选择文件夹后仅复制五个固定数据/许可文件，先校验暂存目录再替换旧目录；用户导入版优先于随附版。坏导入保留现有版本。目录不自动同步，更新插件无需升级主程序。

`StickerService` 管理设置、搜索、预览、当前轮选择及专用 `ToolPort`。`ToolRouter` 合并表情和原有软件能力，按当前轮发现的工具路由。表情没有“操作软件”状态，因此不会触发玩手机动作。现有协调器仍只向桌面聊天提供工具，外部渠道与主动唤醒不获得表情工具。

`dafeiyu_sticker_search` 按上游的加权字段/中文双字匹配思路检索，避开最近五张已选表情；`dafeiyu_sticker_send` 仅接收目录 ID，重新检查开关、套组、单张禁用和离线设置。每轮最多选择一张，成功下载后记录；最终回复通过 `decorateReply` 附图，再落盘并展示。选择失败、取消或授权变化不会附图，工具错误交回模型继续文字回复。

`StickerCache` 使用 URL 与预期哈希的 SHA-256 生成固定文件名。网络请求拒绝重定向、不发送凭据、20 秒超时，流式读取限制 8 MiB。完整文件必须满足目录声明的字节数、GIF 类型、画布尺寸和 SHA-1 前缀才提交。缓存总量 128 MiB，优先淘汰较旧项。读取不跟随文件链接，清理仅处理缓存内约定文件名；取消及退出会中止下载。

`petsticker://local/<sha256>.gif` 仅映射当前有效目录中的已缓存图像，协议请求本身不联网。普通 Markdown 图片依旧只显示替代文字，CSP 仅增加该本地协议；renderer 没有任意文件读取或远程图片能力。图片固定展示框避免加载时挤动滚动位置，语音不会朗读图片链接。

`StickersPanel` 提供开关、搜索、分页、动态预览、逐张禁用和独立导入。首次点击预览才下载，已缓存的分页项可以直接展示。手动气泡预览不创建对话事件，不调用模型、Anki 或动作执行器。

## 本地图片库（2026-11-01）

`src/main/stickers/local.ts` 管理独立的 `stickers/local/catalog.json` 和图片副本，不进入下载缓存的淘汰流程。主进程原生多选框交付文件路径，IPC 不接受渲染进程或模型指定的任意路径。按文件头及 `sharp` 实际解码识别 PNG/JPEG/WebP/GIF，检查大小、尺寸与帧数；只解码首帧以检测常见坏文件，所有原始字节直接保存，不把动画重编码成静态图。`sharp` 是随应用发布的运行时依赖，只在导入时动态加载。

内容 SHA-256 是稳定 ID 和副本文件名，相同文件重复导入保留已编辑资料；副本损坏时可由相同原图修复。每张分别写入临时文件并原子替换索引，批次中的坏图不回滚成功项。读取检查普通文件、字节数和完整哈希；索引损坏时备份索引、保留图像。原图不属于宿主管理范围，删除操作只移除库内副本与条目。

`LibrarySticker` 联合远程与本地条目，远程插件不能占用 `custom:` ID 或“我的表情”套组。本地条目与远程条目复用搜索、工具路由、每轮一张、禁用及聊天显示；没有远程插件时仍可使用本地库。名称、情绪、关键词与场景由用户编辑，是模型选择的依据，不声称有视觉识别。元数据修订通知让搜索结果及时刷新；导入、编辑、删除会取消旧选图，退出等待在途本地写入。

图片协议增加固定哈希文件名的 `.png/.jpeg/.webp` 后缀，按实际导入格式提供 MIME，仍只能读取当前目录登记的资源。删图立即撤销其协议地址；清理下载缓存和更新插件不触碰本地库。界面分别展示下载缓存计数与本地图片计数。

## 输入框选择器（2026-11-01）

`ExpressionPicker` 为两个聊天输入框共用的组件，Emoji 与表情包使用独立子页。`useChatDraft` 管理文字光标、待发送图片和选择器开关；图片经主进程准备成功才进入草稿，不因为点击选图就发送。语音沿原通道直接提交，但不携带手工草稿。

聊天请求只增加可选 `stickerId`，空文字必须有附件。`CompanionService` 在同一操作锁与取消信号内调用 `StickerService.composeUserMessage`，重新确认目录、图片与修订后生成可信的本机图片 Markdown。历史复用既有显示方式，名称与描述供模型理解表情；上下文明确没有图像像素。最多 4000 字的原文完整保留，附图后仍在事件 8000 字预算内。

新增受限 `sticker-picker` IPC，只接收 state/search/prepare，允许小屋和快捷聊天主 frame，拒绝气泡和其他 renderer；prepare 不允许 bubble 标记或管理操作。用户明确选择与自动选图权限分离，离线和图片校验仍生效，不占用本轮大肥鱼的自动表情。

快捷窗口只接收两个布尔布局标记（选择器、附件），按固定高度调整原生窗口并约束在显示器工作区，不能传任意窗口尺寸。收起时撤销该窗口引起的角色上移，保留用户自行调整的位置。Escape 优先收起选择器，草稿与选择器可保持悬停窗口。
