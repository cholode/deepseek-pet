# 大肥鱼 · 桌宠

一个可离线运行的 Windows 桌宠。Electron + React 管理窗口与小屋，Live2D Cubism Core 驱动原图拆件模型，PixiJS 8 负责桌面合成与特效。动作、动作组和图片序列均由本地 JSON 定义。

## 1.5.0 可操作软件与插件框架

桌宠小屋新增 **可操作软件**。下载并解压插件后导入插件目录，添加软件、定位目录并关联插件，连接后逐项选择允许大肥鱼调用的能力，再从桌面聊天提出任务。支持多个软件、本地 stdio 插件与 MCP Streamable HTTP 服务、独立授权、加密令牌、取消和重启恢复。

本版只提供通用框架，**未内置具体软件操作插件**；软件是否可操作取决于对应插件。导入不会自动执行代码，目录本身不是系统沙箱。新增软件无需修改桌宠主程序。见[使用及插件开发规范](docs/SOFTWARE_PLUGINS.md)和[零能力开发模板](examples/software-plugin-template/README.md)。

## 1.4.5 每晚 21 点自动日记

大肥鱼按本机时间每天 **21:00 自动写日记**，不用打开日记页。程序未运行而漏掉的日期，下次启动会按日期逐篇补齐；从本版首次启动当天开始记录。已完成的日期不会重复自动生成，失败会保留待办并在15分钟后重试，休眠恢复也会检查漏写。

有当天对话且已配置模型时使用模型整理；没有该日记录时如实留下说明，不编造离线期间的经历，也不为没有资料的日期额外请求模型。补记不使用当前心情替代历史心情。可在 **小屋 → 智能陪伴 → 日记** 查看待补写天数、最近完成日期和保存位置，仍可手动再记一笔。

### 1.4.4 大肥鱼的日记

在 **小屋 → 智能陪伴 → 日记** 点击“写今天的日记”。已启用模型时，大肥鱼会根据当天仍保留的桌面对话写第一人称日记；未配置模型时保存离线纪事。按本地日期生成 `大肥鱼日记-YYYY-MM-DD.md`，同日再次写会追加，并可在界面按日期查看。

源码运行及仓库内的发布程序默认写到项目根目录；可以输入绝对目录或“选择文件夹”，保存地址后重启仍有效。移出仓库的便携包默认写到 EXE 同目录，独立安装版默认写到“文档/大肥鱼日记”。改位置不移动旧日记。项目内日记已加入 Git 忽略规则，不随程序打包。详见[日记说明](docs/COMPANION.md#日记)。

### 1.4.3 聊天与状态小菜单

大肥鱼脚下的输入框下方新增“聊天 / 状态”菜单。“状态”显示实时动作、心情、自动活动、陪伴模式和语音开关；“聊天”回到长条输入框，保留未发送草稿。查看状态无需连接模型；未启用情绪时会明确显示“尚未启用”。两页自动调整窗口高度，底部空间不足时临时上移角色，切回聊天或收起后释放多占用的空间。

### 1.4.2 贴近角色的对话气泡

回复改为带小尖角的蓝色对话气泡，按角色头部定位；上方空间不足时移到侧边并调整尖角方向。输入框改成大肥鱼脚下的简洁长条，只保留输入与发送，输出中同一个按钮可停止。屏幕底部空间不足时临时上移角色，收起后恢复位置。模型设置和完整历史仍在小屋中。

### 1.4.1 悬停聊天与流式气泡

鼠标停在大肥鱼身上会弹出聊天框，点击输入后按 Enter 发送，Shift + Enter 换行。回复以蓝色矩形气泡流式显示，自动按文字调整宽高和换行，并避让屏幕边缘。气泡不抢焦点，拖动角色会收起聊天窗口；完整长回复也可在小屋中查看。需要先在智能陪伴中配置模型。

### 1.4.0 智能陪伴

新增可配置人格、长期记忆、情绪变化、主动搭话和约定；支持本地语音、绑定 QQ 通道及经授权的 MCP 工具调用。核心、存储、模型和通道按职责拆分，并补充中文注释与自动化测试。入口：小屋 → **智能陪伴**。配置方法与当前限制见 [使用说明](docs/COMPANION.md)。

## 直接使用

推荐分享 `release/DeepBlue-Setup-1.5.0-win-x64.exe`：安装向导会安装到用户程序目录，并创建桌面与开始菜单快捷方式。安装后移动或删除源码文件夹不会影响使用。

免安装使用 `release/DeepBlue-Desktop-Pet-1.5.0-win-x64.exe`：单个文件包含运行环境、Live2D 运行库和全部素材，普通模式无需 Node.js、账号或网络；智能陪伴需另行配置模型。把它保留在固定位置，首次启动会自动解压。便携 EXE 本身被移动后，手工指向它的快捷方式仍需更新。

两个 EXE 均未签名；若系统策略拒绝运行，请勿关闭安全策略。实际验证结果见 docs/TEST_REPORT.md。

- 单击头部：摸摸头；单击身体：全身缩一下。设置里可以更换绑定动作。
- 移动鼠标：眼神随鼠标上下左右移动；空闲时自动眨眼、呼吸、摆尾与摆动发梢。
- 双击角色：打开“桌宠小屋”；右键角色：打开菜单。
- 按住并移动超过 6 DIP：播放被拎起挣动的动画并跟随鼠标；水平拖动产生惯性甩动，急停或反向时回摆，头发与鲸尾延迟跟随。拖动可超出屏幕工作区，松手恢复站立并归位到最近工作区，拖动不会误触单击。
- 正常情况下，人物区域可交互，透明空白区域近似穿透。
- 开启全部穿透后，从托盘选择“恢复交互”，或按 `Ctrl + Alt + P`。
- 托盘提供显示、隐藏、重置位置、恢复交互和退出。关闭小屋不退出桌宠。
- 固定位置会禁止拖动和所有移动动作。关闭漫游只影响自动散步。

## 开发与构建

在项目根目录运行（支持整个项目目录移动或改名）：

```powershell
npm install
npm run dev
npm run typecheck
npm run lint
npm run test
npm run build
npm run dist:win
```

`npm run start` 运行已构建版本。`npm run test:watch` 是监听测试，普通 `test` 会自动退出。`dist:win` 会先检查类型并构建，然后生成 Windows x64 安装版和便携版。没有签名证书，不配置假签名。

本机实际验证版本：Node **24.20.0**、npm **11.19.0**、Electron **44.2.0**、PixiJS **8.20.1**、React **19.2.8**、TypeScript **5.9.3**、electron-vite **5.0.0**、Vite **7.3.6**、electron-builder **26.15.3**、Vitest **3.2.7**、Zod **4.5.4**。以 `package-lock.json` 锁定的依赖为准；复现安装可使用 `npm ci`。

本机默认 Electron 下载源连接失败，改用镜像成功安装：

```powershell
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
node node_modules/electron/install.js
```

这个环境变量只用于开发下载，程序运行时不访问镜像。

## 不写 TypeScript，增加一个动作

1. 打开小屋 → **动作组 → 导入动作包**。
2. 选择 `examples/custom-action-pack`（便携版解压资源中也附带此示例）。
3. 列表出现“点头后开心挥手”，点击预览即可。它同时引入一个新的点头 motion。
4. 点击“打开用户动作包目录”，修改已导入包中的 JSON 和 `pack.json` 清单，然后点击“重新加载”。无需编译。

完整教程：[动作包格式](docs/ACTION_PACKS.md)。加载失败会保留旧的可用快照。修改导入前的原文件夹不会自动修改已经复制到用户目录的包。

## 配置与存储

配置和用户动作包位于 Electron `userData`（本程序默认 `%APPDATA%\deepblue-desktop-pet`，可通过界面打开动作包子目录）。`settings.json` 保存大小、开关、位置、点击绑定和以完整组 ID 为键的覆盖项；`action-packs/` 保存导入的动作包。不会修改安装目录里的内置 JSON。损坏配置会重命名备份再恢复默认值。

## 素材与 AI 边界

桌面站立状态使用用户确认的 **三视图原画拆件 Live2D 模型**：38 个独立网格、24 个参数。眼白、虹膜、眼睑分离，眨眼使用剪裁遮罩，瞳孔不会被压扁；尾巴、头发、鱼耳独立绑定。运行文件和 Core 均位于 `src/renderer/public/live2d/`，随构建打包，无需本机制作目录。小屋预览、水光序列也使用模型的画面。

睡觉保留已确认的 AI 盖被子素材，只从站立进入，结束或取消后恢复 Live2D。现有 JSON 动作经适配器驱动新模型，部件幅度限制在正面原画可支撑的范围；已支持表情嘴型，大角度侧转和语音口型尚未制作。`npm run assets` 是旧版 AI 组件制作脚本，请勿用它覆盖当前预览和水光序列。素材来源和运行库许可见 [素材说明](docs/ASSET_SOURCES.md)。

1.4.0 已提供可选智能陪伴：人格、聊天、持久记忆、情绪、主动搭话、本地语音、QQ 与 MCP。进入小屋 → 智能陪伴 → 陪伴设置配置。普通模式默认离线；模型、QQ 和 MCP 均需连接自己的服务。详见 [智能陪伴使用与架构](docs/COMPANION.md) 和 [AI 接口](docs/FUTURE_AI.md)。
